# 🔐 Gerador de Senhas Seguras

Projeto desenvolvido em Python para gerar senhas fortes através da linha de comando (CLI).

## 📋 Sobre o Projeto

Criado com o objetivo de ajudar as pessoas a reforçarem sua segurança digital, gerando senhas fortes para proteger contas e informações pessoais.

## ✨ Funcionalidades

* Geração de senhas aleatórias
* Utilização da biblioteca `secrets` para maior segurança
* Validação do tamanho mínimo da senha
* Tratamento de entradas inválidas
* Cópia automática da senha para a área de transferência

## 🚀 Como Executar

### 1. Clone o repositório

```bash
git clone https://github.com/candidohenrique/gerador-senhas.git
```

### 2. Acesse a pasta do projeto

```bash
cd gerador-senhas
```

### 3. Instale as dependências

```bash
pip install -r requirements.txt
```

### 4. Execute o programa

```bash
python main.py
```
